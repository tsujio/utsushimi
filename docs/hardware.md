## GPIOの割り当てと予約

### 外部電極：暫定割り当て・回路図確認済み

Step 1では、画面のタッチコントローラーとは別にESP32-S3内蔵の静電容量タッチ機能を使用します。筐体上面に3枚の銅箔電極A/B/Cを並べます。

| 電極 | GPIO／内蔵タッチチャンネル | V2のJ8ヘッダーピン番号 |
| --- | --- | --- |
| Touch A | GPIO1 / TOUCH1 | 3 |
| Touch B | GPIO7 / TOUCH7 | 13 |
| Touch C | GPIO8 / TOUCH8 | 15 |

**検証結果：** [公式V2回路図][schematic]のGPIO表とJ8配線では、これら3本は外部へ引き出されており、記載された基板上の周辺機能には接続されていません。[Espressifのタッチ対応表][touch]でも内蔵タッチチャンネルを確認しました。回路図上の競合は見当たらないため、代替割り当ては提案していません。電極の実機動作を試験するまでは暫定割り当てとします。配線前にJ8と実物ソケットの向きを照合してください。ヘッダーピン番号とGPIO番号は別です。

各電極は **510Ωの直列抵抗** を介して接続します。これはノイズ低減・保護を目的とした推奨構成であり、静電容量検出の原理上必須ではありません。Espressifはチップ側に直列抵抗を配置し、470Ω〜2kΩの範囲で510Ωを優先し、試験で調整することを推奨しています。初期試作ではブレッドボード上に抵抗を置き、GPIO側の配線を短くします。抵抗だけで完全なESD保護が成立するわけではありません。[出典：Espressifハードウェア設計ガイド][touch]。

### 基板上の既存機能用：予約済み

以下はV2回路図で確認した接続です。Step 1で使わない機能であっても、その理由だけで流用しません。

| GPIO／エキスパンダー端子 | 既存の接続先 |
| --- | --- |
| GPIO0 | BOOTボタン |
| GPIO2 / 4 / 5 / 6 | microSD CS／クロック／MOSI／MISO |
| GPIO3 | 画面タッチ割り込み |
| GPIO9 / 10 | AMOLED CS／クロック |
| GPIO11 / 12 / 13 / 14 | AMOLEDデータ0／1／2／3 |
| GPIO15 / 16 / 17 | バッテリーボタン／制御／電圧測定 |
| GPIO18 | I/Oエキスパンダー割り込み |
| GPIO19 / 20 | USB D- / D+ |
| GPIO21 | AMOLED TE |
| GPIO47 / 48 | 共有I2C SDA / SCL |
| EXIO0 / EXIO1 | AMOLEDリセット／画面タッチリセット |
| EXIO2 / EXIO3 / EXIO4 | RTC割り込み／IMU割り込み2／IMU割り込み1 |

EXIO端子はTCA9554の端子であり、ESP32のGPIO番号ではありません。メモリや起動に関係する端子など、ほかの使用済み端子も空き端子として扱わないでください。この表は予約一覧であり、利用可能なMCU端子を網羅した表ではありません。

共有I2Cバスには画面タッチコントローラー、IMU、RTC、TCA9554が接続されています。将来センサーを追加する場合は、全デバイスのアドレス、電圧レベル、プルアップ、バス負荷を確認します。表示のみを扱う場合も、ディスプレイのリセットにI/Oエキスパンダーを使用するため、このバスを維持します。

### 将来拡張用：プロジェクト方針による予約

- GPIO38〜42は、将来のI2Sマイク、オーディオCodec／アンプ、関連信号のためStep 1では使用しません。
- GPIO43/44（UART TX/RX）は、UART、デバッグ、拡張用として極力温存します。
- 個別のI2S信号は部品選定後に決めます。GPIO Matrixを使う周辺機能は、それ以前に不要な固定割り当てを行いません。
- microSDの将来利用を維持し、Step 1の都合で将来用GPIOを消費しません。
- 変更時は公式V2回路図・ピン定義と再照合します。競合が生じた場合は、無断で確定せず、見直した割り当て案を提示します。

## はんだ付けなしのタッチ試作

暫定的な組み立て方法は以下のとおりです。

1. 下敷きなどの非導電性プラスチック板の裏面に、銅箔テープの電極を3枚貼ります。反対側の絶縁面に触れて検出します。
2. ジャンパワイヤの金属ピンを銅箔の露出面に接触させ、テープで固定します。テープの粘着剤に導電性があることは前提にしません。
3. 各電極をブレッドボード上の直列抵抗に接続します。
4. 上記の割り当てに従い、オス-オスのジャンパワイヤで基板のメスソケットに接続します。

初期試作でははんだ付けを必須としません。接触の安定性、電極寸法・間隔、被覆の厚さ、配線長は要検証です。仮配線を固定し、通電前に短絡がないことを確認します。ジェスチャーの解釈は[アーキテクチャ](architecture.md#身体イベント)、検出のマイルストーンは[ロードマップ](roadmap.md)で扱います。

### Step 1.3初期確認：電極Aだけの配線

公式V2回路図のJ8では、1番がGND、3番がIO1、5番がIO2で、奇数側に並びます。これは回路図上の番号であり、基板を見たときの左右を指定するものではありません。実物の印字・1番位置と照合して、**J8の3番＝GPIO1＝TOUCH1** を特定してください。GPIO3やJ8の1番とは異なります。

1. USB-Cを抜いて電源を切ります。この節はAの接続方法です。現在の3電極構成では次節に従いB/Cも追加します。
2. 銅箔を1枚、非導電性プラスチック板の裏面へ貼ります。指は反対側のプラスチック面に置きます。
3. 銅箔の露出した金属面にジャンパワイヤの金属ピンを接触させ、テープで固定します。接着面の導通は仮定しません。
4. ブレッドボードで、電極側のワイヤと510Ω抵抗の一端を同じ接続列へ、抵抗の他端とGPIO側のワイヤを別の接続列へ挿します。抵抗の両端を同じ接続列へ挿して短絡させないでください。
5. GPIO側のオスピンをJ8の3番メスソケットに接続します。GPIOから抵抗までを短くし、配線を固定します。
6. 電源を切ったまま導通・隣接端子との短絡を確認してからUSB-Cを接続します。

```text
J8 pin 3（GPIO1 / TOUCH1）──510Ω──銅箔電極A
                                      │ プラスチック板で絶縁
                                      指
```

電極をGND・3.3V・5Vへ接続する配線は不要です。電極Aは上記の信号線1本で接続します。抵抗値はメーカー推奨に基づきますが、電極寸法・板厚・配線長・接触の安定性は未検証です。初期実装は測定値を観察するためのもので、閾値や接触判定の成立を保証しません。[書き込み・測定・切り分け手順](../firmware/main/README.md#電極aの初期動作確認)を参照してください。

### 将来の3電極の配線と確認

現在のファームウェアはA/B/Cを測定します。下記の配線を追加して検証します。電極Aの接触判定は試作条件で確認済みです。3電極の走査と試作の撫で反応は確認していますが、感度と相互干渉の詳細評価は未完了です。GPIO・J8番号は上記の割り当て表を正とします。

USBを抜き、Aと同じ構成でB/Cを追加します。**各電極に510Ωを1本ずつ**入れ、電極やブレッドボードの信号列を互いに接続しないでください。プラスチック板の裏にA/B/Cの順で並べ、表面にも位置を示す目印を付けます。電極の寸法・間隔・被覆厚は未確定で、試作条件を記録してください。近接する電極や配線間の結合は実測で確認します。

抵抗や配線の取り回しは電極Aの手順と同じです。3枚とも指を離した状態で起動・校正し、各電極を個別に触れた際に、隣の電極の値と判定も確認してください。撫でと表情の試験手順はファームウェア文書を参照してください。

## Step 2.1：MAX98357Aの音声出力

### 購入済み部品と確認範囲

所有者確認済み：MAX98357AモノラルI2Sアンプ1個、4Ω 3Wスピーカー2個を購入し、アンプのピンヘッダーとスピーカー端子ははんだ付け済みです。今回はスピーカー1個だけを接続します。基板の表裏写真ではMAX98357A・V914・Default 9dBの印字と、SD/VIN付近の「105」表示の抵抗を確認しています。販売元の回路図、抵抗の実測値、コンデンサ容量、各はんだ付け箇所の導通は未確認です。

所有者の測定報告はVIN約5V、SD約0.5V、アンプから外したスピーカーの直流抵抗約4Ωです。測定器・給電時の負荷条件は未記録です。出音とタッチとの共存を確認した条件・残る制約は[ファームウェアの検証状況](../firmware/main/README.md#音声出力の検証状況)を参照してください。

### 配線とGPIOの根拠

固定リビジョンの[公式V2回路図][schematic]のJ8とGPIO表では、GPIO38/39/41は外部へ露出し、基板上の既存機能や電極A/B/Cと競合しません。音声用に予約していたGPIO38〜42のうち3本を使用し、Step 2.2ではGPIO40をマイク入力に使用し、GPIO42とUART43/44は温存します。電極の割り当て変更は不要です。今回の試作で使用する配線ですが、筐体組み込み後の電気的な検証は残るため暫定割り当てとします。

USBを抜いて電源を切り、J8の1番位置と実物の印字を照合して接続します。J8のピン番号とGPIO番号は別です。

| MAX98357Aモジュール | 本体Rev2.0／接続先 | 条件 |
| --- | --- | --- |
| VIN | J8 31番：USB_5V（5V） | USB給電時の電源。BATや3V3ではない |
| GND | J8 33番：GND | 本体と共通GND |
| BCLK | J8 19番：GPIO38 | ESP32から出力 |
| LRC / LRCLK / WS | J8 21番：GPIO39 | ESP32から出力 |
| DIN | J8 25番：GPIO41 | ESP32のDOUTからアンプのDINへ |
| GAIN | 未接続 | IC仕様では開放時9dB。モジュール回路の詳細は未確認 |
| SD / SD_MODE | 未接続 | 購入モジュールでは約0.5Vを実測。別モジュールでは要確認 |
| SPK+ / OUTP | スピーカーの一端 | 4Ω 3Wを1個のみ |
| SPK− / OUTN | 同じスピーカーの他端 | GNDへ接続しない |

スピーカー2個の並列接続は行いません。BTL出力なのでスピーカーの両端をアンプ出力へ接続し、いずれもGNDや他の機器へ接続しません。

### 電気的条件

[Analog Devices MAX98357A/MAX98357Bデータシート Rev.16](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX98357A-MAX98357B.pdf)のIC仕様では、電源は2.5〜5.5V、デジタル入力はVIH最小1.3V／VIL最大0.6Vで、ESP32-S3の3.3V I2S信号と整合します。MCLKとI2C制御は不要です。MAX98357AはPhilips I2S、MAX98357Bは左詰めなので型番を混同しません。

SD_MODEは内部100kΩプルダウンを持ち、IC端子だけを開放すると停止します。SD未接続での動作はモジュール側の抵抗回路に依存します。今回の約0.5Vという実測値は左右平均の選択範囲（0.355〜0.65V）と整合し、同条件で出音を確認しています。SDの抵抗回路自体は未確認です。モジュールを交換する場合は回路図またはSD電圧を確認します。プルアップがないと確認できた場合の代替案はSDを本体3.3Vへ接続して左チャンネルを選択する方法ですが、既存回路との短絡がないことを確認してから適用します。今回のPCMは左右同値です。

V2回路図ではJ8 31番はUSBコネクターのVBUSと同じUSB_5Vネットで、D2を介して本体VCCへも給電されます。外部アンプ用の許容余剰電流は規定されていません。USBホスト／充電器・ケーブル・端子・基板配線を含む総電流の余裕は未測定で、3Wを供給できる保証はありません。4Ω・5Vで大出力にすると3Wを超える条件もあり、PCM振幅だけで出力電力や消費電流は保証できません。

アンプ近傍のデカップリング容量をメーカー資料と照合し、負荷時のUSB_5V電圧降下・brownout/reset・発熱を確認します。給電不足時の代替案はアンプ用の安定化5V電源と共通GNDですが、USBへ逆給電しない接続構成を別途確認します。5VをESP32のGPIOへ入力しません。

### タッチとの共存に必要な配置

試作では、I2S送信と同期してタッチのrawが低下する条件を確認しています。無音PCMでも、スピーカーを外しても再現し、アンプ完全切離しとVIN/GNDのみの接続では大きな低下がありません。信号配線からの結合と、クロック入力時のアンプ動作・給電経路の影響は未分離です。

試作写真ではアンプがタッチ用ブレッドボードの近くにあり、音声側の長い配線束がタッチ配線の近くを通っています。現在はアンプを本体の近くに置き、音声配線を電極・タッチ配線から離して並走を避けます。スピーカー線も対にまとめ、タッチ配線から離します。タッチ側を固定した配置で再校正し、条件を変える際も配線位置を記録します。

この配置で出音とC保持・身体更新・描画・瞬きの継続を確認しています。ただし送信中のraw低下は残り、干渉の解消や条件を変えた安定性の保証ではありません。[Espressifの配線ガイド](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/pcb-layout-design.html#touch-sensor)に従い、タッチ配線を短くし、チップ側の510Ω直列抵抗を維持します。有効な離隔距離は実測で確認します。

### Step 2.2：INMP441マイク1個

所有者が指定・接続した確定配線です。V2回路図のJ8ではGPIO40は23番に露出し、既存周辺機能・電極とは競合しません。GPIO38/39はアンプと共用し、GPIO41は引き続きアンプ専用です。

| INMP441 | 本体／接続先 |
| --- | --- |
| VDD | 3V3 |
| GND | GND |
| SCK | GPIO38 |
| WS | GPIO39 |
| SD | GPIO40 |
| L/R | GND（左） |

**所有者確認済み：** マイク単体のSD–GND間は約100kΩ、通電時のVDD–GND間は約3.3Vです。静かな区間に対する声・拍手のRMS変化を実機確認済みです。詳細な検証範囲は[ファームウェア](../firmware/main/README.md#step-22音声入力とrmsログ)を参照してください。

[INMP441データシート DS-INMP441-00 Rev.1.1](https://product.tdk.com/system/files/dam/doc/product/sw_piezo/mic/mems-mic/data_sheet/inmp441.pdf)の電源範囲は1.8〜3.3V、音声は24bit符号付きPhilips I2Sで、1フレーム64クロックが必要です。48kHz・32bit×左右2スロットではBCLK=3.072MHzとなり資料上整合します。L/R=GNDの左スロットだけを使用します。右スロットと左の下位8bitは集計しません。100kΩのSDプルダウンは非駆動区間に必要な構成と整合しますが、購入モジュールの回路図・0.1µFデカップリング実装は未確認です。

I2S構成は[アーキテクチャ](architecture.md#step-22の音声入力と共有i2s)に集約します。クロックは入力有効時に常時動作するため、既存の配線離隔を維持し、起動時校正・raw・誤接触・保持・撫でへの影響を再確認します。2個目のマイクは対象外です。

残りの確認事項：

- [ ] モジュール回路、GAIN/SD抵抗、デカップリング容量を確認する。
- [ ] 負荷時の電圧・電流・発熱・起動停止ノイズを測定する。
- [ ] 発音中の新規接触・離脱・撫で反応と、配置・電源・筐体条件を変えた再現性を確認する。
