# ハードウェア

## 確認状況と本体サイズ

本体は約100 × 100 × 100 mm以内に収める想定です。基本は据え置きとし、回転・移動は交換可能な外部デバイスが担います。

**所有者による確認済み事項（2026-10-17）：** Waveshare ESP32-S3-Touch-AMOLED-2.41を購入済みで、PCBの `Rev2.0` 印字を実物で確認済みです。GPIO用メスソケットも実装済みです。到着・リビジョン確認TODOは完了しています。基板の識別は完了し、公式V2デモの表示成功もユーザーから報告されています（2026-10-18）。電極Aの接触・離脱に対応する測定値の変化と、独自ファームウェアの表示・瞬きの継続を確認済みです。実測の範囲と制約は[ファームウェアの確認状況](../firmware/main/README.md#確認状況)を参照してください。

## GPIOの割り当てと予約

### 外部電極：暫定割り当て・回路図確認済み

Step 1では、画面のタッチコントローラーとは別にESP32-S3内蔵の静電容量タッチ機能を使用します。筐体上面に3枚の銅箔電極A/B/Cを並べます。

| 電極 | GPIO／内蔵タッチチャンネル | V2のJ8ヘッダーピン番号 |
| --- | --- | --- |
| Touch A | GPIO1 / TOUCH1 | 3 |
| Touch B | GPIO7 / TOUCH7 | 13 |
| Touch C | GPIO8 / TOUCH8 | 15 |

**検証結果：** [公式V2回路図][schematic]のGPIO表とJ8配線では、これら3本は外部へ引き出されており、記載された基板上の周辺機能には接続されていません。[Espressifのタッチ対応表][touch]でも内蔵タッチチャンネルを確認しました。回路図上の競合は見当たらないため、代替割り当ては提案していません。電極の実機動作を試験するまでは暫定割り当てとします。配線前にJ8と実物ソケットの向きを照合してください。ヘッダーピン番号とGPIO番号は別です。

各電極は **510Ωの直列抵抗** を介して接続します。これはノイズ低減・保護を目的とした推奨構成であり、静電容量検出の原理上必須ではありません。Espressifはチップ側に直列抵抗を配置し、470Ω〜2kΩの範囲で510Ωを優先し、試験で調整することを推奨しています。初期試作ではブレッドボード上に抵抗を置き、GPIO側の配線を短くします。抵抗だけで完全なESD保護が成立するわけではありません。[出典：Espressifハードウェア設計ガイド][touch]。

### 基板上の既存機能用：予約済み

以下はV2回路図で確認した接続です。Step 1で使わない機能であっても、その理由だけで流用しません。

| GPIO／エキスパンダー端子 | 既存の接続先 |
| --- | --- |
| GPIO0 | BOOTボタン |
| GPIO2 / 4 / 5 / 6 | microSD CS／クロック／MOSI／MISO |
| GPIO3 | 画面タッチ割り込み |
| GPIO9 / 10 | AMOLED CS／クロック |
| GPIO11 / 12 / 13 / 14 | AMOLEDデータ0／1／2／3 |
| GPIO15 / 16 / 17 | バッテリーボタン／制御／電圧測定 |
| GPIO18 | I/Oエキスパンダー割り込み |
| GPIO19 / 20 | USB D- / D+ |
| GPIO21 | AMOLED TE |
| GPIO47 / 48 | 共有I2C SDA / SCL |
| EXIO0 / EXIO1 | AMOLEDリセット／画面タッチリセット |
| EXIO2 / EXIO3 / EXIO4 | RTC割り込み／IMU割り込み2／IMU割り込み1 |

EXIO端子はTCA9554の端子であり、ESP32のGPIO番号ではありません。メモリや起動に関係する端子など、ほかの使用済み端子も空き端子として扱わないでください。この表は予約一覧であり、利用可能なMCU端子を網羅した表ではありません。

共有I2Cバスには画面タッチコントローラー、IMU、RTC、TCA9554が接続されています。将来センサーを追加する場合は、全デバイスのアドレス、電圧レベル、プルアップ、バス負荷を確認します。表示のみを扱う場合も、ディスプレイのリセットにI/Oエキスパンダーを使用するため、このバスを維持します。

### 将来拡張用：プロジェクト方針による予約

- GPIO38〜42は、将来のI2Sマイク、オーディオCodec／アンプ、関連信号のためStep 1では使用しません。
- GPIO43/44（UART TX/RX）は、UART、デバッグ、拡張用として極力温存します。
- 個別のI2S信号は部品選定後に決めます。GPIO Matrixを使う周辺機能は、それ以前に不要な固定割り当てを行いません。
- microSDの将来利用を維持し、Step 1の都合で将来用GPIOを消費しません。
- 変更時は公式V2回路図・ピン定義と再照合します。競合が生じた場合は、無断で確定せず、見直した割り当て案を提示します。

## はんだ付けなしのタッチ試作

暫定的な組み立て方法は以下のとおりです。

1. 下敷きなどの非導電性プラスチック板の裏面に、銅箔テープの電極を3枚貼ります。反対側の絶縁面に触れて検出します。
2. ジャンパワイヤの金属ピンを銅箔の露出面に接触させ、テープで固定します。テープの粘着剤に導電性があることは前提にしません。
3. 各電極をブレッドボード上の直列抵抗に接続します。
4. 上記の割り当てに従い、オス-オスのジャンパワイヤで基板のメスソケットに接続します。

初期試作でははんだ付けを必須としません。接触の安定性、電極寸法・間隔、被覆の厚さ、配線長は要検証です。仮配線を固定し、通電前に短絡がないことを確認します。ジェスチャーの解釈は[アーキテクチャ](architecture.md#身体イベント)、検出のマイルストーンは[ロードマップ](roadmap.md)で扱います。

### Step 1.3初期確認：電極Aだけの配線

公式V2回路図のJ8では、1番がGND、3番がIO1、5番がIO2で、奇数側に並びます。これは回路図上の番号であり、基板を見たときの左右を指定するものではありません。実物の印字・1番位置と照合して、**J8の3番＝GPIO1＝TOUCH1** を特定してください。GPIO3やJ8の1番とは異なります。

1. USB-Cを抜いて電源を切ります。この節はAの接続方法です。現在の3電極構成では次節に従いB/Cも追加します。
2. 銅箔を1枚、非導電性プラスチック板の裏面へ貼ります。指は反対側のプラスチック面に置きます。
3. 銅箔の露出した金属面にジャンパワイヤの金属ピンを接触させ、テープで固定します。接着面の導通は仮定しません。
4. ブレッドボードで、電極側のワイヤと510Ω抵抗の一端を同じ接続列へ、抵抗の他端とGPIO側のワイヤを別の接続列へ挿します。抵抗の両端を同じ接続列へ挿して短絡させないでください。
5. GPIO側のオスピンをJ8の3番メスソケットに接続します。GPIOから抵抗までを短くし、配線を固定します。
6. 電源を切ったまま導通・隣接端子との短絡を確認してからUSB-Cを接続します。

```text
J8 pin 3（GPIO1 / TOUCH1）──510Ω──銅箔電極A
                                      │ プラスチック板で絶縁
                                      指
```

電極をGND・3.3V・5Vへ接続する配線は不要です。電極Aは上記の信号線1本で接続します。抵抗値はメーカー推奨に基づきますが、電極寸法・板厚・配線長・接触の安定性は未検証です。初期実装は測定値を観察するためのもので、閾値や接触判定の成立を保証しません。[書き込み・測定・切り分け手順](../firmware/main/README.md#電極aの初期動作確認)を参照してください。

### 将来の3電極の配線と確認

現在のファームウェアはA/B/Cを測定します。下記の配線を追加して検証します。電極Aの接触判定は試作条件で確認済みです。3電極同時走査での動作・相互干渉は未検証です。GPIO・J8番号は上記の割り当て表を正とします。

USBを抜き、Aと同じ構成でB/Cを追加します。**各電極に510Ωを1本ずつ**入れ、電極やブレッドボードの信号列を互いに接続しないでください。プラスチック板の裏にA/B/Cの順で並べ、表面にも位置を示す目印を付けます。電極の寸法・間隔・被覆厚は未確定で、試作条件を記録してください。近接する電極や配線間の結合は実測で確認します。

抵抗や配線の取り回しは電極Aの手順と同じです。3枚とも指を離した状態で起動・校正し、各電極を個別に触れた際に、隣の電極の値と判定も確認してください。撫でと表情の試験手順はファームウェア文書を参照してください。

## 電源

**確定方針：** 本体はバッテリーレスとします。

| 段階 | 給電方針 |
| --- | --- |
| 開発中 | PCのUSB-Cから給電・書き込み |
| Step 1完成後 | USB充電器からUSB-C経由で5V給電 |
| 回転台座 | 台座から本体へ給電。連続回転用にスリップリングを検討 |
| 移動台座 | 市販の外部USBモバイルバッテリーなどから給電 |

ESP32-S3基板へ高電圧を直接入力しません。必要電流、逆流防止、複数電源の同時接続、電圧降下、スリップリング経由の給電は、該当するステップで設計・検証します。ここでは動作電流の定格や電源経路の検証完了を示していません。

## 外部身体デバイス

**設計上の決定事項：** 回転台座・移動台座は独立したMCUを持ち、本体の同一性を再定義せずに交換・追加できる構成とします。能力ベースのインターフェース方針は[アーキテクチャ](architecture.md#身体apiの方向性)を参照してください。

**未確定の候補：** 台座コントローラーはESP32-C3-Zero、本体との通信はBLEです。既存記録には台座コントローラーの購入・動作成功の根拠がないため、いずれも未確認とします。将来の回転機構には、モーター、モータードライバー、エンコーダ、スリップリングを想定しています。Step 1では台座ハードウェアや通信プロトコルを実装しません。
