# Step 1 身体状態・欲求・瞬き・表情の仕様

## 位置づけ

この文書はStep 1のローカルな身体反応モデルを定義する。KOKOROが担う人格、学習、長期記憶、高度な意思決定とは分離する。実装状況・実機検証状況は[ファームウェア](../firmware/main/README.md)、開発順序は[ロードマップ](roadmap.md)、責務分離は[アーキテクチャ](architecture.md)を参照する。

**状態：** 以下は設計上の合意事項であり、現行ファームウェアへの実装・実機検証が完了したことを意味しない。具体的な計算式の係数・閾値は、以下で明示したものを除き暫定である。

## 処理モデル

```text
TouchSensor / PettingDetector
  | touch_started / touch_ended / petting_detected
  v
Stimulus --------------------------+
  |                                |
  v                                v
BodyState (dryness, valence) --> Desire (eye_moisture_need)
  |                                |
  |                                v
  |                           Decision (blink?)
  |                                |
  |                                v
  |                           Action (single / double blink)
  |                                |
  +<--------- dryness recovery ----+
  |
  v
Expression (valence -> eye openness)
  |
  +----> EyeRenderer <---- Action blink animation
```

入力・意味イベント・内部状態・意思決定・行動・描画を分離する。瞬きと表情の制御は非ブロッキングとし、センサー処理を止めない。瞬きの決定と描画フレームの更新を混同しない。

## 身体状態と刺激

- `eye_dryness` (`d`): 0〜1。0は潤っている、1は乾燥している。時間経過で増加し、瞬き行動の実行で減少する。
- `valence` (`v`): -1〜1。負は不快、正は快。独立した身体状態として保持する。KOKOROの人格・永続的な感情ではない。
- `holding` (`h`): 接触中の刺激状態（真偽値）。`touch_started` と `touch_ended` によって更新する。どの接触を保持と判定するかはタッチ検出の校正で決める。
- `petting_detected`: 撫で動作の離散イベント。単なる継続接触を撫でとみなさない。
- `eye_moisture_need` (`z`): 乾燥度から計算する欲求であり、別の永続状態として保持しない。

乾燥が強い場合は不快方向へ `valence` を変化させる。この結合はStep 1に含める。別個のストレス状態は導入しない。

## 状態更新の暫定数式

経過時間を `Δt` 秒として、乾燥度は以下の連続時間モデルを基本とする。

```text
dd/dt = k_d (1 - d)
k_d = -ln(0.4) / blink_interval
```

この係数は「乾燥度0から開始して blink_interval 秒後に0.6へ達する」基準であり、実際の平均瞬き間隔が `blink_interval` になることを保証しない。

欲求の暫定関数：

```text
z(d) = clamp((d - 0.3) / 0.7, 0, 1)^2
```

快・不快の暫定更新モデル：

```text
dv/dt = -v / comfort_decay_time
        + holding_sensitivity * h
        - dryness_discomfort_strength * phi(d)

phi(d) = max(0, (d - theta) / (1 - theta))^2
```

- `petting_detected` で `v = clamp(v + petting_sensitivity, -1, 1)`。
- `d` は0〜1、`v` は-1〜1に制限する。
- 不快開始閾値 `theta = 0.8` はシミュレーションに基づく**暫定推奨値**。実機での表情を確認して決める。

## 瞬きの意思決定と行動

瞬きの発生は欲求 `z(d)` に応じた確率的な判定とする。一定周期で機械的に瞬きする方式にはしない。実装は経過時間に応じた確率を使用し、更新周期が変わっても極端に挙動が変わらないようにする。

- `blink_interval = 5秒` は**瞬き行動の開始から次の開始までの実測平均の目標**。乾燥度の時定数だけを5秒に設定して終わりとせず、シングル・ダブル・不応期を含めたシミュレーションで発生率を較正する。
- 瞬き行動を選んだ後、10%の確率でダブルブリンク、それ以外はシングルブリンクを選ぶ。
- ダブルブリンクは**1つの行動**であり、2回の瞬きの間隔は100msを初期値とする。2回目の瞬きは新しい意思決定として扱わない。
- 乾燥度の回復はシングルでもダブルでも**1行動につき1回**。`d = (1 - blink_recovery) * d` とする。
- **不応期は瞬き行動の終了から1秒**。不応期中は次の瞬き行動を開始しない。ダブルブリンク内部の2回目には適用しない。
- 瞬きのアニメーションと時間管理は非ブロッキングとする。

瞬き判定の確率関数の形、係数、較正後の値、乱数生成方法、ダブルの「100ms」の厳密な起点は実装前の調整事項とする。既存ファームウェアの「終了後2〜6.5秒、ダブル約25%」は現行実装の記録であり、上記の**目標仕様とは異なる**。既存動作を仕様適合済みと扱わない。

## 表情への反映

正の `valence` は目を細める表情として表現する。負の `valence` の具体的な目の形はStep 1では追加確定しない。

```text
target_openness = 1 - squint_strength * max(0, v)
d(expression_openness)/dt =
    (target_openness - expression_openness) / expression_response_time
render_openness = expression_openness * blink_animation_openness
```

- `blink_animation_openness` は瞬き行動が返す0〜1の開眼率。
- 表情と瞬きの開眼率は合成して `EyeRenderer` に渡す。
- 表情状態を描画処理から独立させ、画像切り替えではなく数値パラメータで描画する。

## 調整可能な振る舞いパラメータ

以下の9個をユーザーが調整できるパラメータとして設計する。値は初期候補であり、実機の印象を確認して変更できるようにする。内部閾値・確率関数の指数・不応期・ダブル確率などは、現時点では公開調整項目に含めない。

| パラメータ | 初期値 | 意味 |
| --- | ---: | --- |
| `blink_interval` | 5 s | 瞬き行動の平均間隔の目標 |
| `blink_duration` | 150 ms | 瞬き時間の調整基準。具体的な開閉配分は実装時に整理 |
| `blink_recovery` | 0.8 | 1行動あたりの乾燥度回復率 |
| `comfort_decay_time` | 20 s | `valence` が中立へ戻る時定数 |
| `petting_sensitivity` | +0.35 / event | 撫でイベントによる快方向の変化 |
| `holding_sensitivity` | +0.02 / s | 保持刺激中の快方向への変化率 |
| `squint_strength` | 0.5 | `v=1` における目の細まりの強さ |
| `expression_response_time` | 200 ms | 表情追従の時定数 |
| `dryness_discomfort_strength` | 0.1 / s | 乾燥による不快方向への変化率 |

`blink_duration=150ms` は新モデルの調整候補であり、現行ファームウェアに記録された「閉70ms・保持40ms・開150ms」の合計260msとは一致しない。既存アニメーションの置換時に時間定義と見え方を確認する。

## 実装時に決める事項・検証

- 更新周期（現行の瞬き状態更新10ms、表示約20msを参考とする）、イベントキュー、イベントと状態更新の適用順序、時間刻みの扱い。
- 乾燥度・快不快の初期値、時間経過や一時停止からの復帰、乱数シード。
- 平均5秒の較正条件（計測対象は瞬き**行動**の開始時刻、ダブル内部の2回目は除外）、分布の検証、シミュレーションの再現可能なテスト。
- 単発／二連の時系列、終了判定、ダブル間隔100msの基準、乾燥回復の適用タイミング。
- タッチ由来の保持状態と撫でイベントの確定方法、複数電極や連続イベントの扱い。
- 実機でのちらつき、瞬き・表情の自然さ、描画応答性、接触中の入力処理継続。

これらは未決定・未検証であり、合意済みの上位仕様を変更せずに検討する。
