# UTSUSHIMI

UTSUSHIMIは、特定の身体に依存しない知性 **KOKORO** に物理的な身体を与えるプロジェクトです。身体は交換可能であり、デバイスが変わってもKOKOROの同一性や記憶は維持されるべきものです。

## 現在の状況

現在の開発対象は **Step 1 — 身体的コミュニケーション** です。KOKOROなしでも、電源を接続すると目を開き、撫でられると目で反応する身体を目指します。

本体基板は購入済みで、PCBリビジョンも実物で確認済みです。確認済みの機器情報と暫定配線方針は[ハードウェア](docs/hardware.md)を参照してください。ESP-IDF v5.5.6での `hello_world` と公式V2表示デモの成功がユーザーから報告されています。丸い白目・黒い瞳の表示に加え、身体状態から独立したワイブル分布による単発・二連の瞬きと、撫で・保持の意味イベントから快不快・表情を更新する身体反応モデルを実装しました。実電極の入力は未接続です。ビルド・書き込み手順と検証範囲は[ファームウェア](firmware/main/README.md)を参照してください。実機確認を残しており、まず完了させるマイルストーンは[Step 1.1 — 画面表示](docs/roadmap.md#step-11--画面表示)です。
