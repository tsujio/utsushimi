# UTSUSHIMI

UTSUSHIMIは、特定の身体に依存しない知性 **KOKORO** に物理的な身体を与えるプロジェクトです。身体は交換可能であり、デバイスが変わってもKOKOROの同一性や記憶は維持されるべきものです。

## 現在の状況

現在の開発対象は **Step 2.3 — オフラインウェイクワード「アイリス」と探索視線** です。ESP-SR / WakeNet10による認識とBehavior経由の探索を実装しています。描画をCPU0・認識をCPU1へ分離した実機試験では、10回の認識・探索が完了し、約3分55秒のログに音声欠落・再起動はありません。CPU分離後のタッチ・撫でとの共存、認識精度・見た目・長時間安定性の評価は残っています。[設定・検証範囲・実機試験](firmware/main/README.md#step-23ウェイクワードと探索視線)と[ロードマップ](docs/roadmap.md#step-23--ウェイクワード認識と探索視線現在の対象)を参照してください。

Step 2.2では、INMP441の入力と既存のMAX98357A電子音出力を共有クロックで動かす実装を追加しています。ESP-IDF v5.5.6でのビルドとホスト回帰試験は成功し、所有者が声・拍手へのRMS反応、電子音の出音、瞬き・タッチ・撫での基本動作を確認しています。長時間安定性とタッチ干渉の評価は残っています。[検証手順](firmware/main/README.md#step-22音声入力とrmsログ)と[ロードマップ](docs/roadmap.md#step-22--マイク1個の音声取得とrmsログ)を参照してください。Step 2.1の確認済み条件と残課題は[音声出力の検証状況](firmware/main/README.md#音声出力の検証状況)に記載しています。

本体は購入済みのWaveshare ESP32-S3-Touch-AMOLED-2.41 Rev2.0です。Step 1の目の表示・瞬き・接触時の視線反射・撫でによる表情反応を実装し、所有者が試作機の12時間稼働後にも動作を確認しています。基板の識別・配線・電源条件は[ハードウェア](docs/hardware.md)、ビルド・書き込み・検証範囲は[ファームウェア](firmware/main/README.md)に集約しています。
