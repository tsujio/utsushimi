# UTSUSHIMI

UTSUSHIMIは、特定の身体に依存しない知性 **KOKORO** に物理的な身体を与えるプロジェクトです。身体は交換可能であり、デバイスが変わってもKOKOROの同一性や記憶は維持されるべきものです。

## 現在の状況

現在の開発対象は **Step 1 — 身体的コミュニケーション** です。KOKOROなしでも、電源を接続すると目を開き、撫でられると目で反応する身体を目指します。

本体基板は購入済みで、PCBリビジョンも実物で確認済みです。確認済みの機器情報と暫定配線方針は[ハードウェア](docs/hardware.md)を参照してください。ファームウェアは未実装で、公式デモの実行と開発環境の構築も未着手です。次のマイルストーンは[Step 1.1 — 画面表示](docs/roadmap.md#step-11--画面表示)です。
