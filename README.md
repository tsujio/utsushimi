# UTSUSHIMI

UTSUSHIMIは、特定の身体に依存しない知性 **KOKORO** に物理的な身体を与えるプロジェクトです。身体は交換可能であり、デバイスが変わってもKOKOROの同一性や記憶は維持されるべきものです。

## 現在の状況

現在の開発対象は **Step 2.1 — 最小音声出力** です。MAX98357Aとスピーカー1個で電子音を生成し、既存の目・瞬き・タッチ・撫でへの反応と共存させます。試作では出音と、送信中のC保持・身体更新・描画・瞬きの継続を確認しています。確認条件・残る制約は[ファームウェアの検証状況](firmware/main/README.md#音声出力の検証状況)、作業範囲は[ロードマップ](docs/roadmap.md#step-21--最小音声出力)を参照してください。

本体は購入済みのWaveshare ESP32-S3-Touch-AMOLED-2.41 Rev2.0です。Step 1の目の表示・瞬き・接触時の視線反射・撫でによる表情反応を実装し、所有者が試作機の12時間稼働後にも動作を確認しています。基板の識別・配線・電源条件は[ハードウェア](docs/hardware.md)、ビルド・書き込み・検証範囲は[ファームウェア](firmware/main/README.md)に集約しています。
